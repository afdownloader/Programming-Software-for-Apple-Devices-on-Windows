Put optional helper programs here (or choose their path inside the app):

  zsign.exe              - signs the iOS Template.ipa on Windows   (project: github.com/zhlynn/zsign)
  ideviceinstaller.exe   - installs an IPA on the iPhone over USB   (project: libimobiledevice)
  idevice_id.exe, ideviceinfo.exe  - detect the iPhone              (libimobiledevice)

Keep the DLLs that come with the libimobiledevice tools in the same folder.
The iPhone also needs "Apple Devices" (Microsoft Store) or iTunes installed so Windows has Apple's USB driver.
